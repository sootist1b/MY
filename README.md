# demo — Executive Operations Dashboard

`index.html` 하나를 브라우저에서 열면 동작하는 단일 HTML 대시보드입니다. 빌드·CDN·API 키가 필요하지 않습니다. 모든 값은 **가상 샘플**이며 실제 업무 실적이 아닙니다.

## 화면

| 탭 | 본문 | 그래프 |
| --- | --- | --- |
| 통합현황 | DRAM 12행 + 추가 시연 FLASH 3행, 전체 15행 × 36열 | 없음 |
| 입고실적 | 기존 원본 12행 × 22열 | 당월 생산 계획 트리맵 / 당월 입고 진척일 일별 꺾은선 / 당월 거래선별 계획 누적 막대 |
| 공출실적 | 기존 원본 21행 × 23열 | 당월 공출 필요량 트리맵 / 당월 공출 진척일 일별 꺾은선 / 당월 Site별 계획 누적 막대 |
| 공급진척 | 기존 원본 12행 × 30열 | 당월 FABOUT 생산계획 트리맵 / 최근 3개월 FABOUT 진척 일별 꺾은선 / 최근 3개월 WF가용 재공 누적 막대 |
| 자재확보 | 기존 원본 16행 × 18열 | Substrate / PCB / PMIC 상태별 품목 수 파이차트 |
| 차트라이브러리 | 70개 독립 샘플 | 카테고리·검색·확대·후보 저장 |

통합현황은 그래프 없이 전체 표가 본문을 채웁니다. 각 업무 화면은 간단한 한 줄 필터, 지정된 그래프 3개, 전체 상세표를 사용합니다. 자재의 RCD 행도 상세표에는 유지합니다.

## 원본과 추가 시연 데이터

기존 HTML에는 생산계획, 거래선, Site, FABOUT, WF 가용재공의 일별 이력 및 FLASH 통합 데이터가 없습니다. 이 필드는 사용자 요청에 따라 `planning-data.js`의 **별도 시연 데이터**로 작성했습니다. 기존 원본 상세표의 값은 교체하지 않습니다. 추가 시연 차트에는 실제 업무 수치가 아니라는 설명을 표시합니다. 통합 표에 함께 표시하는 FLASH 행도 추가 시연임을 표시합니다.

상단 **추가 시연 포함 / 원본 기준**으로 전환합니다. 원본 기준에서는 미제공 차트가 데이터 없음 상태가 되고 통합 표에는 기존 DRAM 12행만 표시합니다. 자재 파이차트는 두 모드 모두 기존 `materialRows`를 사용합니다.

시연 기준일은 `2026-10-26`, 당월은 `2026-10`, 최근 3개월은 `2026-08~10`입니다. 실제 현재일이나 실시간 연동을 의미하지 않습니다.

- 트리맵: 제품군별 월 생산계획 또는 공출 필요량의 합계에 면적이 비례합니다.
- 입고/공출 진척일: `시연 누적 실적 / (해당 월 시연 계획 / 월 일수)`입니다. 기준 진척일과 비교합니다.
- 거래선/Site 누적 막대: 해당 월 시연 계획을 제품군별로 나누며, 같은 달 생산계획/공출계획과 합계가 일치합니다. 공출 필요량과 공출계획은 별도 필드입니다.
- 최근 3개월 FABOUT 추이: STATUS 또는 Salescode별 진척을 실제 날짜 축에서 비교합니다. 10월은 기준일인 26일까지만 그립니다.
- WF 가용재공: 각 날짜의 STATUS별 가용 wafer 스냅샷을 누적 막대로 표시합니다. 날짜끼리 합산하지 않습니다.
- 자재 파이차트: 각 자재군 내 STATUS별 **품목 수**가 분모입니다. 수량이나 금액의 비중이 아닙니다.

## 필터·표·상세정보

검색·분류·기간·상태·열별 조건을 AND로 적용합니다. 헤더 클릭으로 오름차순 → 내림차순 → 원본 순서를 전환하고, 숫자는 숫자 크기로 정렬합니다. 열 필터는 포함·같음·숫자 이상/이하를 지원합니다. CSV에는 현재 조회된 모든 원본 열과 정렬된 행을 담습니다. 탭 진입과 초기화는 해당 탭의 전체 데이터를 표시합니다.

동일한 상위 분류 안에서 연속된 기본정보 값은 세로 병합합니다. 수량·실적·상태는 병합하지 않습니다. 셀을 클릭하면 원본 행의 전체 필드를 볼 수 있고, 병합 셀에서는 포함된 행을 각각 선택할 수 있습니다.

입고·공출·공급 탭의 맵은 **제품군 × STATUS** 영역으로 표시합니다. 초록=정상, 노랑=주의, 빨강=위험입니다.

- 기본 꺾은선은 정상·주의·위험을 각각 집계해 함께 표시합니다. STATUS는 현재 조회 범위에서 품목별 최신 원본 행을 기준으로 연결하며, 과거 월을 선택하면 그 월의 상태를 적용합니다. 진척일은 해당 계열의 누적 실적 합계 / 일평균 계획 합계로 계산합니다.
- 맵 영역 클릭 시 해당 제품군·STATUS 안의 **Salescode별 계열**로 드릴다운합니다. 추가 시연 마스터에 품목당 3개 Salescode를 명시적으로 정의했으며, 매일의 계획·실적·WF 재공은 분할 전 합계를 보존합니다. Salescode는 실제 코드가 아닙니다.
- 기본 누적막대는 STATUS별로 쌓습니다. 맵 영역 선택 후에는 해당 영역의 STATUS만 표시합니다. 거래선/Site별 계획과 WF 가용재공 모두 같은 규칙을 사용합니다.
- 같은 영역을 다시 누르거나 상단 선택 칩의 × 또는 초기화를 누르면 전체 STATUS 보기로 돌아갑니다. 탭 전환과 상단 분류 조건 변경 시 맵 선택도 해제합니다.
- 최근 3개월 FABOUT 꺾은선은 실제 날짜 순서로 연결합니다. 월별 계획을 기준으로 한 진척일이므로 월초에 다시 시작합니다. 기준일 이후의 미래 점은 그리지 않습니다. 관측 대상이 없는 상태는 선을 만들지 않고 범례에 `(없음)`으로 표시합니다.

거래선/Site 막대와 파이 조각은 관련 원본 품목으로 필터링합니다. 거래선/Site 연결은 **추가 시연 마스터**에 따른 연결입니다. 일별 시연 추이는 상세표에 없는 별도 데이터이므로 점에 날짜·값 툴팁을 제공하고 원본에 없는 날짜 필터를 임의로 적용하지 않습니다.

가독성을 위해 탭·필터·차트 제목·범례·표 글씨를 확대했습니다. 표의 긴 필드명은 한글 업무명으로 보여주고, 원본 키는 헤더 툴팁·셀 상세정보·CSV에 유지합니다. 전체 행·열을 보존하기 위해 낮은 해상도에서는 표 폰트만 사용 가능한 높이에 맞춰 조절합니다.

셀 색상은 빨강=위험, 노랑=주의, 초록=정상입니다. 비율·계획 대비 실적의 시연 기준은 ≥95% 정상, ≥80% 주의, 미만 위험입니다. 0건은 중립색입니다. 실제 업무 적용 시 공식 기준과 원본 데이터 연동이 필요합니다.

## 개발과 검증

수정 소스는 `dashboard.js`, `dashboard.css`, `chart-samples.js`, `planning-data.js`입니다. 변경 후 단일 HTML에 반영합니다.

```sh
python scripts/embed-dashboard.py
python -m http.server 8000 --bind 0.0.0.0
```

브라우저 회귀 테스트:

```sh
npm install --prefix /tmp/my-dashboard-test --cache /tmp/my-npm-cache playwright --no-audit --no-fund
NODE_PATH=/tmp/my-dashboard-test/node_modules node tests/dashboard.cjs
```

기본 Chromium 경로는 `/usr/bin/chromium`, 테스트 URL은 `http://127.0.0.1:8000`입니다. `CHROMIUM_PATH`, `DASHBOARD_URL`로 변경할 수 있습니다. 6개 탭, 원본 셀 보존, 시연 데이터 경계, 지정 그래프, 파이 합계, 병합·상세·필터·정렬·CSV, 70종 갤러리와 PC 1366×768 / 1440×900 / 1920×1080의 넘침을 검증합니다. 작은 화면이나 더 큰 데이터에서는 전체 표 동시 표시와 가독성 간 조정이 필요합니다.
