# MY — Executive Operations Dashboard

경영진용 MYD 운영 대시보드의 HTML 프로토타입입니다.

- **실행:** `index.html`을 브라우저에서 열어 사용합니다. 별도의 빌드나 서버가 필요하지 않습니다.
- **화면:** 통합 현황 / 상세 분석 01~04 / 상세 분석 05 차트 라이브러리.
- **통합 현황:** 36개 전체 열, 두 단계 헤더, 같은 분류값의 세로 병합, PC 화면에서 스크롤 없는 매트릭스.
- **데이터:** 모든 회사명·ITEM·수치·차트는 검토용 **샘플 데이터**입니다. 실제 실적을 나타내지 않습니다.

프로토타입은 기능과 디자인 확인을 위한 용도이며, 실제 데이터 연동과 권한·접근 제어는 추후 구현해야 합니다.
